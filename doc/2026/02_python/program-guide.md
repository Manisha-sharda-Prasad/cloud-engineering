# Guide
## Looping:
- `for item in items`
  - Anything Iterable
  - eg: "name"
  - eg: collection - list, set, dict/map/k:v
- `while (condition)`
  - while True:
  - while False:
  - while 5 < 10:
  - `while x < 10`

---
## Useful built-in Functions:
- `range(7,15)` ⭐️
  - array . iterable, [7,8,....,15]
  - > gives number array
-  `enumerate( items)` --> return item and its index
    - eg: [item1, item2, item3]
    - item1 + index = 0
    - item2 + index = 1
    - item3 + index = 2
    - > gives index as well

- `len()`
- `print(x,y,z,...)` : comma separated var/s
- `print(var1)` | `print(f"my var {var1}")`
