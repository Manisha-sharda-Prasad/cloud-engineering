## 🎯 Study Strategy & Time Allocation
Target **18–22 hours per week** following this recommended weekly split:
- **40% Learn:** Video lectures, textbooks, documentation.
- **30% Hands-on:** Python coding, AWS labs, architecture diagrams, ML notebooks.
- **20% Active Recall:** Teaching concepts, closed-book diagramming, explaining trade-offs.
- **10% Review:** Flashcards, summary notes, competency verification checklists.
