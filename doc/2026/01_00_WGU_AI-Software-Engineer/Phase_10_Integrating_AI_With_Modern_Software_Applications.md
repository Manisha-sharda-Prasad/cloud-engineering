## 2. Comprehensive Study Topics

### 2.1 AI Data Architecture & Vector Databases (Week 23)
- **Data Modalities:** Structured, Semi-structured (JSON), Unstructured (Text, Audio, Images).
- **Data Pipelines:** Ingestion, Cleaning, Chunking, Embeddings generation.
- **Vector Databases:**
  - *Concepts:* High-dimensional vector space, cosine similarity, Euclidean distance, Nearest Neighbor search.
  - *Technologies:* Pinecone, ChromaDB, PGVector, Qdrant.
  - *RAG Architecture:* Retrieval-Augmented Generation pattern.

### 2.2 Model Architecture & Inference Patterns (Week 24)
- **Inference Models:** Batch Inference vs. Real-Time Streaming Inference.
- **Model Serving Approaches:**
  - Direct SDK inclusion vs. Microservice API wrapping (FastAPI, TorchServe, Triton).
- **ML Pipelines:** Data Ingestion $ightarrow$ Preprocessing $ightarrow$ Model Inference $ightarrow$ Post-processing API Response.

### 2.3 Cloud System Architecture for AI (Week 25)
- **AI Application Topology:**
  $$	ext{User/Client} ightarrow 	ext{API Gateway} ightarrow 	ext{App Microservice} ightarrow 	ext{Async Queue (SQS)} ightarrow 	ext{AI Model Service} \leftrightarrow 	ext{Vector DB / Cache}$$
- **Scalability & Resiliency:** Load balancing, horizontal auto-scaling, response caching (Redis), fallback mechanisms.

### 2.4 AI Risk Management & Mitigation (Week 26)
- **Technical AI Risks:**
  - *Hallucination:* Incorrect outputs generated by generative models.
  - *Prompt Injection:* Malicious input overriding system prompts.
  - *Data Leakage / Privacy:* Confidential data sent to external AI APIs.
  - *Model / Data Drift:* Degradation of accuracy over time.
- **Mitigation Controls:** Guardrails (NeMo Guardrails, Guidance), input sanitization, output validation schemas (Pydantic), strict API rate-limiting, continuous drift alerts.
